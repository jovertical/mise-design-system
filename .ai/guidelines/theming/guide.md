# Theming

`src/lib/tokens/` turns a `ThemeConfig` into CSS. Nothing else writes theme CSS.

- `tailwind-palette.ts` is generated by `scripts/copy-tailwind-palette.ts`.
  Never edit it by hand.
- `presets.ts` holds the bases, `defaultTheme` (zinc, indigo; D11) and
  Storybook's presets.
- `config.ts` turns a `ThemeConfig` into a `ResolvedTheme`, and fails loudly on
  an unknown hue or an incomplete ramp.
- `semantic.ts` holds the public token contract (`SEMANTIC_TOKENS`) and its
  light and dark values. Values point at role ramps (`var(--color-primary-600)`),
  never at literals. The exceptions are white and the translucent dark-mode
  borders.
- `emit-web.ts` writes the `@theme inline` bridge, `:root`, `.dark`, base and print.

## Rules

- **A bridge line never points a utility at a ramp step.**
  `--color-primary: var(--color-primary-600)` would freeze `bg-primary` in one
  scheme. `tests/theme.test.ts` enforces it.
- **A new semantic token** goes into `SEMANTIC_TOKENS` and into both scheme
  functions, in the same position. The test checks both blocks.
- **Ramp values are literals in `:root`,** because Tailwind prunes theme
  variables nobody uses.
- **The faces and `--radius` live in `:root`,** with self-references in the
  bridge, so a consumer can override them in plain CSS. Tailwind also writes
  those self-references into its theme layer. They are harmless, because the
  unlayered `:root` wins the cascade.
- **`--radius-button`** (the config's `buttonRadius`) is in `:root` with no
  bridge: Button reads it through `rounded-[var(--radius-button,9999px)]`,
  so a theme file generated before the token existed still gets the round default.
- **`components.css`** is for what a class string cannot say. It is appended
  after the generated theme.

## The three consumer levels

1. Import `theme.css`.
2. Override semantic tokens in CSS after the import.
3. Generate a replacement with `npx mise-theme <config> -o <file>`.

Storybook's Theme toolbar runs level 3's emitter at runtime and applies the
result as level 2.
