# The consumer skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo the user has chosen inline execution in the main session.

**Goal:** Ship a `mise` agent skill in `skills/mise/` (and in the npm tarball) that teaches agents in consuming apps which mise component to use and how, with a generated props catalogue, setup and theming guides, type-checked recipes, and a `mise-theme info --json` command for live project context.

**Architecture:** A hand-written `SKILL.md` plus reference files read on demand. `scripts/build-skill.ts` generates `skills/mise/components/<group>.md` from each component's exported Props type, JSDoc and `$props()` defaults, using the TypeScript compiler; `tests/skill.test.ts` fails when the committed catalogue is stale. Recipes are real `.svelte` files checked by `svelte-check`. `mise-theme info` is a read-only subcommand of the existing CLI.

**Tech Stack:** TypeScript ~6.0 compiler API, tsx, Vitest 5, svelte-check, SvelteKit 3 (config in `vite.config.ts`), the `skills` CLI (`npx skills`).

**Spec:** `docs/specs/2026-11-09-consumer-skill-design.md`

## Global Constraints

- Package name `@jovertical/mise-design-system`; form entry `@jovertical/mise-design-system/form`.
- The skill's folder is `skills/mise/`; its frontmatter `name` is `mise`.
- The description ends with an activation sentence of the form "Activates when …; or when the user mentions …".
- The live-context line uses `npx --no-install mise-theme info --json`, so a missing install fails rather than fetching an unrelated package named `mise-theme`.
- The CLI keeps the name `mise-theme`; no `mise` binary.
- `mise-theme info` reads files and writes nothing.
- Generated files open with `<!-- Generated by pnpm build:skill. Do not edit by hand. -->`.
- Story and recipe copy is generic operations: locations, shifts, orders, stock, registers. No product names, no real businesses, `$` for money.
- Dependencies are installed by the user, never by the agent. `npx skills` downloads a CLI to a temporary cache and installs nothing into the project, but ask the user before its first run.
- Commit only when `pnpm test` and `pnpm build:storybook` both exit 0 (git-workflow skill). Push only after the user approves a phase.
- Phases of at most 5 tasks; stop at each phase gate with a phase-gates report.
- Spec refinement: check 2 covers the names exported by component folders' `index.ts` files. Utilities exported from `src/lib/index.ts` outside component folders (`cn`, the tone maps) are covered in `SKILL.md`'s prose, not the catalogue.

```ts
/**
 * Splits a component file into its two scripts. The module script carries the
 * exported Props type; the instance script carries the `$props()`
 * destructuring, and with it the defaults.
 */
const SCRIPT = /<script\b([^>]*)>([\s\S]*?)<\/script>/g

export function scripts(svelte: string): { module: string | null; instance: string | null } {
  let module: string | null = null
  let instance: string | null = null
  for (const [, attributes, body] of svelte.matchAll(SCRIPT)) {
    if (/\bmodule\b/.test(attributes)) module = body
    else instance = body
  }
  return { module, instance }
}
```

```ts
/**
 * Reads what an agent needs from a Props type: the members declared on it,
 * their JSDoc, what else it takes, and the defaults. Pure; the TypeScript
 * compiler parses, nothing type-checks.
 */
import ts from 'typescript'

export type PropDoc = {
  name: string
  type: string
  optional: boolean
  default: string | null
  description: string
}

export type PropsDoc = { summary: string; props: PropDoc[]; alsoTakes: string[] }

const parse = (source: string) =>
  ts.createSourceFile('x.ts', source, ts.ScriptTarget.Latest, true, ts.ScriptKind.TS)

const oneLine = (text: string) => text.replace(/\s+/g, ' ').trim()

/** The first paragraph of the JSDoc directly above a node, on one line. */
function firstParagraph(node: ts.Node): string {
  const docs = ts.getJSDocCommentsAndTags(node).filter(ts.isJSDoc)
  const text = ts.getTextOfJSDocComment(docs.at(-1)?.comment) ?? ''
  return oneLine(text.split(/\n\s*\n/)[0] ?? '')
}

const TAGS: Record<string, string> = {
  Anchor: 'a', Li: 'li', Input: 'input', Button: 'button', Textarea: 'textarea',
  Table: 'table', Td: 'td', Th: 'th', Img: 'img', Label: 'label', Ol: 'ol', Form: 'form',
}

const ELEMENTS: Record<string, string> = {
  Div: 'div', Span: 'span', Paragraph: 'p', Heading: 'h1>`–`<h6', UList: 'ul', OList: 'ol',
  LI: 'li', TableRow: 'tr', TableSection: 'thead', TableCell: 'td', Table: 'table',
  Anchor: 'a', Button: 'button', Input: 'input', Element: 'element', Nav: 'nav',
}

/** One operand of a Props intersection, in a phrase an agent can act on. */
function describe(node: ts.TypeNode): string {
  const text = oneLine(node.getText())

  if (ts.isParenthesizedTypeNode(node)) return describe(node.type)
  if (ts.isTypeReferenceNode(node)) {
    const name = node.typeName.getText()
    const args = node.typeArguments ?? []
    if (name === 'WithElementRef' && args[0]) return describe(args[0])
    if (name === 'Omit' && args[0] && args[1]) {
      const keys = [...args[1].getText().matchAll(/'([^']+)'/g)].map((match) => `\`${match[1]}\``)
      return `${describe(args[0])} except ${keys.join(', ')}`
    }
    if (name === 'HTMLAttributes') {
      const element = args[0]?.getText().match(/^HTML(\w*)Element$/)?.[1] ?? 'Element'
      return `every \`<${ELEMENTS[element] ?? element.toLowerCase()}>\` attribute`
    }
    const tag = name.match(/^HTML(\w+)Attributes$/)?.[1]
    if (tag) return `every \`<${TAGS[tag] ?? tag.toLowerCase()}>\` attribute`
    const primitive = name.match(/^(\w+)Primitive\.(\w+)Props$/)
    if (primitive) return `bits-ui \`${primitive[1]}.${primitive[2]}\` props`
    const part = name.match(/^(\w+)Props$/)
    if (part) return `everything \`${part[1]}\` takes`
  }
  return `\`${text}\``
}

/** The non-literal operands of a type, flattened through `&` and `|`. */
function operands(node: ts.TypeNode): ts.TypeNode[] {
  if (ts.isParenthesizedTypeNode(node)) return operands(node.type)
  if (ts.isIntersectionTypeNode(node) || ts.isUnionTypeNode(node)) {
    return node.types.flatMap(operands)
  }
  return [node]
}

export function propsDoc(moduleScript: string, typeName: string): PropsDoc | null {
  const source = parse(moduleScript)
  const alias = source.statements.find(
    (statement): statement is ts.TypeAliasDeclaration =>
      ts.isTypeAliasDeclaration(statement) && statement.name.text === typeName,
  )
  if (!alias) return null

  const props: PropDoc[] = []
  const alsoTakes: string[] = []
  for (const operand of operands(alias.type)) {
    if (!ts.isTypeLiteralNode(operand)) {
      const phrase = describe(operand)
      if (!alsoTakes.includes(phrase)) alsoTakes.push(phrase)
      continue
    }
    for (const member of operand.members) {
      if (!ts.isPropertySignature(member) || !member.type) continue
      const name = member.name.getText()
      if (props.some((prop) => prop.name === name)) continue
      props.push({
        name,
        type: oneLine(member.type.getText()),
        optional: member.questionToken !== undefined,
        default: null,
        description: firstParagraph(member),
      })
    }
  }

  return { summary: firstParagraph(alias), props, alsoTakes }
}

/**
 * The defaults in `let { a = 1, b, ref = $bindable(null), ...rest } = $props()`.
 * A key mapped to `null` is a binding with no default; `...rest` is left out.
 */
export function propDefaults(instanceScript: string): Map<string, string | null> {
  const defaults = new Map<string, string | null>()
  const visit = (node: ts.Node) => {
    if (
      ts.isVariableDeclaration(node) &&
      ts.isObjectBindingPattern(node.name) &&
      node.initializer &&
      ts.isCallExpression(node.initializer) &&
      node.initializer.expression.getText() === '$props'
    ) {
      for (const element of node.name.elements) {
        if (element.dotDotDotToken) continue
        const key = (element.propertyName ?? element.name).getText()
        defaults.set(key, element.initializer ? defaultText(element.initializer) : null)
      }
      return
    }
    ts.forEachChild(node, visit)
  }
  visit(parse(instanceScript))
  return defaults
}

/** `$bindable(x)` is a default of `x`; `$bindable()` is none. */
function defaultText(initializer: ts.Expression): string | null {
  if (ts.isCallExpression(initializer) && initializer.expression.getText() === '$bindable') {
    const [value] = initializer.arguments
    return value ? oneLine(value.getText()) : null
  }
  return oneLine(initializer.getText())
}
```

```ts
/** The names a component folder's index.ts re-exports, in source order. */
import ts from 'typescript'

export type ExportDoc = { name: string; from: string; component: boolean; typeOnly: boolean }

export function folderExports(indexSource: string): ExportDoc[] {
  const source = ts.createSourceFile('index.ts', indexSource, ts.ScriptTarget.Latest, true)
  return source.statements.flatMap((statement) => {
    if (
      !ts.isExportDeclaration(statement) ||
      !statement.moduleSpecifier ||
      !statement.exportClause ||
      !ts.isNamedExports(statement.exportClause)
    ) {
      return []
    }
    const from = (statement.moduleSpecifier as ts.StringLiteral).text
    return statement.exportClause.elements.map((element) => ({
      name: element.name.text,
      from,
      component: element.propertyName?.text === 'default' && from.endsWith('.svelte'),
      typeOnly: statement.isTypeOnly || element.isTypeOnly,
    }))
  })
}
```

```ts
/**
 * The component catalogue an agent in a consuming app reads: one Markdown
 * file per group, each component with its import, summary, props table and
 * what else it takes. Generated so it cannot drift from the Props types;
 * tests/skill.test.ts compares it with the committed copy.
 */
import { existsSync, readdirSync, readFileSync } from 'node:fs'
import { join } from 'node:path'

import { type ExportDoc, folderExports } from './exports.js'
import { type PropsDoc, propDefaults, propsDoc } from './props.js'
import { scripts } from './svelte-source.js'

const PACKAGE = '@jovertical/mise-design-system'
const HEADER = '<!-- Generated by pnpm build:skill. Do not edit by hand. -->'

export const skillDir = (root: string) => join(root, 'skills', 'mise')

const subfolders = (path: string) =>
  readdirSync(path, { withFileTypes: true })
    .filter((dirent) => dirent.isDirectory())
    .map((dirent) => dirent.name)
    .sort()

const title = (group: string) => group[0].toUpperCase() + group.slice(1).replace(/-/g, ' ')

const cell = (text: string) => text.replace(/\|/g, '\\|')

function partDoc(folderPath: string, entry: ExportDoc): (PropsDoc & { name: string }) | null {
  const file = join(folderPath, entry.from)
  if (!existsSync(file)) return null
  const { module, instance } = scripts(readFileSync(file, 'utf8'))
  const doc = module ? propsDoc(module, `${entry.name}Props`) : null
  if (!doc) return null
  const defaults = instance ? propDefaults(instance) : new Map<string, string | null>()
  return {
    name: entry.name,
    ...doc,
    props: doc.props.map((prop) => ({ ...prop, default: defaults.get(prop.name) ?? null })),
  }
}

function renderPart(part: PropsDoc & { name: string }, heading: string): string[] {
  const lines = [heading, '']
  if (part.summary) lines.push(part.summary, '')
  if (part.props.length > 0) {
    lines.push('| Prop | Type | Default | Description |', '| --- | --- | --- | --- |')
    for (const prop of part.props) {
      const name = `\`${prop.name}\`${prop.optional ? '' : ' (required)'}`
      const fallback = prop.default === null ? '' : `\`${cell(prop.default)}\``
      lines.push(`| ${name} | \`${cell(prop.type)}\` | ${fallback} | ${cell(prop.description)} |`)
    }
    lines.push('')
  }
  if (part.alsoTakes.length > 0) lines.push(`Also takes: ${part.alsoTakes.join('; ')}.`, '')
  return lines
}

function renderFolder(root: string, group: string, folder: string, formFolders: Set<string>) {
  const folderPath = join(root, 'src', 'lib', 'components', group, folder)
  const entries = folderExports(readFileSync(join(folderPath, 'index.ts'), 'utf8'))
  const components = entries.filter((entry) => entry.component)
  const rootPart = components.find((entry) => entry.from === `./${folder}.svelte`) ?? components[0]
  const values = entries.filter((entry) => !entry.component && !entry.typeOnly)
  const types = entries.filter((entry) => entry.typeOnly && !entry.name.endsWith('Props'))
  const entry = formFolders.has(`${group}/${folder}`) ? `${PACKAGE}/form` : PACKAGE
  const imported = [...components, ...values].map((part) => part.name)

  const lines = [`## ${rootPart?.name ?? folder}`, '']
  if (imported.length > 0) lines.push(`\`import { ${imported.join(', ')} } from '${entry}'\``, '')

  const ordered = rootPart ? [rootPart, ...components.filter((part) => part !== rootPart)] : []
  ordered.forEach((part, index) => {
    const doc = partDoc(folderPath, part)
    if (!doc) {
      lines.push(index === 0 ? '' : `### \`${part.name}\``, '')
      return
    }
    const rendered = renderPart(doc, index === 0 ? '' : `### \`${part.name}\``)
    lines.push(...(index === 0 ? rendered.slice(2) : rendered))
  })

  if (values.length > 0) lines.push(`Also exports: ${values.map((v) => `\`${v.name}\``).join(', ')}.`, '')
  if (types.length > 0) lines.push(`Types: ${types.map((t) => `\`${t.name}\``).join(', ')}.`, '')
  return lines
}

export function catalogue(root: string): Map<string, string> {
  const componentsDir = join(root, 'src', 'lib', 'components')
  const formEntry = readFileSync(join(root, 'src', 'lib', 'form.ts'), 'utf8')
  const formFolders = new Set(
    [...formEntry.matchAll(/components\/([\w-]+\/[\w-]+)\/index\.js/g)].map((match) => match[1]),
  )

  const files = new Map<string, string>()
  for (const group of subfolders(componentsDir)) {
    const lines = [HEADER, '', `# ${title(group)}`, '']
    for (const folder of subfolders(join(componentsDir, group))) {
      lines.push(...renderFolder(root, group, folder, formFolders))
    }
    files.set(group, `${lines.join('\n').replace(/\n{3,}/g, '\n\n').trimEnd()}\n`)
  }
  return files
}
```

The root part's heading is the folder's `##` heading, so its own `###` line is dropped (`rendered.slice(2)`); further parts get `### \`Name\``. A part with no readable Props type still gets its heading, so check 2 finds its name.

```ts
/**
 * What an agent needs to know about the app it is working in before it writes
 * mise UI: which version, which stack, where the theme and the stylesheet are.
 * Read-only. The consumer skill runs it on load through `mise-theme info --json`.
 */
import { existsSync } from 'node:fs'
import { readdir, readFile } from 'node:fs/promises'
import { join, relative } from 'node:path'

export type ProjectInfo = {
  version: string
  stack: 'sveltekit' | 'inertia' | 'vite'
  svelte: string | null
  tailwind: string | null
  themeConfig: string | null
  stylesheet: string | null
  form: boolean
}

const THEME_CONFIGS = ['mise.theme.js', 'mise.theme.mjs', 'mise.theme.ts']
const SKIPPED = new Set(['node_modules', '.git', 'vendor', 'dist', 'build', '.svelte-kit', 'storage', 'public'])
const IMPORT = /@import\s+['"]@jovertical\/mise-design-system\//
const MAX_DEPTH = 6

async function findStylesheet(cwd: string, dir = cwd, depth = 0): Promise<string | null> {
  if (depth > MAX_DEPTH) return null
  const entries = (await readdir(dir, { withFileTypes: true })).sort((a, b) =>
    a.name.localeCompare(b.name),
  )
  for (const entry of entries) {
    const path = join(dir, entry.name)
    if (entry.isFile() && entry.name.endsWith('.css') && IMPORT.test(await readFile(path, 'utf8'))) {
      return relative(cwd, path).split('\\').join('/')
    }
  }
  for (const entry of entries) {
    if (!entry.isDirectory() || SKIPPED.has(entry.name) || entry.name.startsWith('.')) continue
    const found = await findStylesheet(cwd, join(dir, entry.name), depth + 1)
    if (found) return found
  }
  return null
}

export async function projectInfo(cwd: string, version: string): Promise<ProjectInfo> {
  const manifestPath = join(cwd, 'package.json')
  if (!existsSync(manifestPath)) throw new Error(`No package.json in ${cwd}`)
  const manifest = JSON.parse(await readFile(manifestPath, 'utf8'))
  const dependencies: Record<string, string> = {
    ...manifest.dependencies,
    ...manifest.devDependencies,
  }
  const has = (name: string) => name in dependencies

  return {
    version,
    stack: has('@sveltejs/kit') ? 'sveltekit' : has('@inertiajs/svelte') ? 'inertia' : 'vite',
    svelte: dependencies.svelte ?? null,
    tailwind: dependencies.tailwindcss ?? null,
    themeConfig: THEME_CONFIGS.find((name) => existsSync(join(cwd, name))) ?? null,
    stylesheet: await findStylesheet(cwd),
    form: has('formsnap') && has('sveltekit-superforms'),
  }
}
```

- [ ] **Step 1: Write `dashboard-page.svelte`**

`PageLayout` with a `PageHeader` (title "Today", a description, a `Button` action), then a `CardGrid` of four `StatTile`s (orders, sales in `$`, average basket, refunds, each with a `DeltaBadge`-style trend where `StatTile` supports it), then a `Card` with a `Chart` of sales by hour, and a `Card` with `MetricBar`s ranking locations. Take each component's props from `skills/mise/components/*.md` and the arrangement from the components' stories: `src/lib/components/layout/page-layout/page-layout.stories.svelte`, `src/lib/components/data-display/stat-tile/stat-tile.stories.svelte`, `src/lib/components/data-display/chart/chart.stories.svelte`, `src/lib/components/data-display/metric-bar/metric-bar.stories.svelte`. `Sidebar` belongs to the app shell, not the page; the `.md` says so and shows the shell in one short snippet taken from `src/lib/components/navigation/sidebar/sidebar.stories.svelte`.

- [ ] **Step 2: Write `form.svelte` and `form-sveltekit.svelte`**

`form.svelte`, for Inertia or plain Svelte: a "New stock item" form in a `Card`: `Field` + `Input` (name), `Field` + `Select` (category, with `items`), `Field` + `QuantityInput` (opening stock), `Field` + `NumberInput format="currency"` (unit cost, in cents), `SwitchField` (track expiry), with errors from a `$state` object shown through `FieldError` and `aria-invalid`, and a submit `Button` with `loading`. The `.md` notes that with Inertia the state is `useForm` from `@inertiajs/svelte` and errors come back from Laravel validation; the component only reads `errors`.

`form-sveltekit.svelte`: the same fields through `Form` from `@jovertical/mise-design-system/form`, based on `src/lib/components/forms/form/form.stories.svelte`'s Playground, with a zod schema. Pass `applyAction: false` only where the story does and say why in a comment.

- [ ] **Step 3: Write `data-table.svelte`**

An orders table with `DataTable`: columns built with `dataTableColumns<Order>()`, the features from `dataTableFeatures`, a toolbar with a search input and a status filter, row selection, pagination, and a `DropdownMenu` of row actions. Base it on `src/lib/components/data-display/data-table/data-table.stories.svelte` ("With toolbar", "With row selection") and `stories/fixtures/device-table.svelte`; status cells use `Badge` with a `tone` per status.
