# Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans, inline in the main session (the user's choice for this repo). Activate the authors-components, vitest-testing, git-workflow and documents-updates skills. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A read-only board in mise: columns of cards grouped by a status, for the logistics example's Orders "Board" view and any app's pipeline.

**Architecture:** Three parts in `src/lib/components/data-display/board/`: `Board` (the horizontally scrolling row of columns), `BoardColumn` (a lane with a header: title, count, a tone dot, optional actions, and its cards or an empty line), and `BoardCard` (a card-surfaced item, a link when given `href`). No drag and drop: moving cards between columns belongs with the deferred Draggable / Droppable / Sortable work.

**Tech Stack:** Svelte 5, Tailwind v4, mise's tone maps, Vitest + Testing Library, Storybook (addon-svelte-csf).

**Spec:** `docs/specs/2026-11-09-logistics-example-design.md`, "Gaps known before the work starts", 1. Parent plan: `docs/superpowers/plans/2026-11-09-logistics-example.md`, Task 10.

## Decisions

| # | Decision | Ruling |
| --- | --- | --- |
| B1 | Origin | `Origin: mise`, decided by the user on 2026-11-09: Board has no React file. `tests/provenance.test.ts` accepts it, and its story tag is `mise` |
| B2 | Group | `data-display` (it shows things, grouped), folder `board`, story title `Data display/Board` |
| B3 | Scope | Read-only. No drag, no reordering, no column collapse. A column shows its cards in the order given |
| B4 | Layout | `Board` is a flex row that scrolls horizontally; each column has a fixed width (`w-72`, `shrink-0`) so a wide board scrolls rather than squeezing four columns into a phone |
| B5 | Column surface | A lane on the canvas: `bg-foreground/[0.04]`, `rounded-xl`, `p-2`. A neutral fill on the canvas is a foreground wash (the neutral-wash rule); `bg-muted` is the canvas and would vanish. Softer than a chip's `/[0.07]` because it covers a large area. Reviewed in screenshots in both schemes and adjusted there if it reads wrong |
| B6 | Column header | `title` (string or snippet), `count` (number, shown as a muted figure), `tone` (a `size-2` dot from `TONE_FILL_CLASS`; `neutral` by default), `actions` (snippet, right-aligned) |
| B7 | Empty column | `empty` (string or snippet), default "Nothing here", shown when the column has no children, in muted text, so a column never collapses to its header |
| B8 | Card | `BoardCard`: `bg-card text-card-foreground rounded-lg border p-3 shadow-xs`, `flex flex-col gap-1`. `href` renders an `<a>` with a hover and a focus ring; otherwise a `<div>` |
| B9 | Tone vocabulary | `tone: Tone`, never `color` or `status` |

- [ ] **Step 3: The parts**

`board.svelte`:

```svelte
<!--
  Origin: mise
  Diverged: none. Board has no React origin; mise authored it for the
    logistics example's Orders board (2026-11-09).
-->
<script lang="ts" module>
  import type { HTMLAttributes } from 'svelte/elements'

  import type { WithElementRef } from '../../../utils/types.js'

  /**
   * Columns of cards grouped by a status: a pipeline read across. Read-only;
   * moving a card between columns is the deferred drag-and-drop work. The row
   * scrolls sideways rather than squeezing its columns, because a card needs
   * its width to say anything.
   */
  export type BoardProps = WithElementRef<HTMLAttributes<HTMLDivElement>>
</script>

<script lang="ts">
  import { cn } from '../../../utils/cn.js'

  let { ref = $bindable(null), class: className, children, ...rest }: BoardProps = $props()
</script>

<div
  bind:this={ref}
  data-slot="board"
  class={cn('flex items-start gap-3 overflow-x-auto pb-2', className)}
  {...rest}
>
  {@render children?.()}
</div>
```

`board-column.svelte`: module script exports `BoardColumnProps = WithElementRef<Omit<HTMLAttributes<HTMLElement>, 'title'>> & { title: string | Snippet; count?: number; tone?: Tone; actions?: Snippet; empty?: string | Snippet }`, each member with JSDoc (`count`: "How many items the column holds, which may be more than it shows"; `empty`: "Shown when the column has no cards, so it never collapses to its header"). Instance script destructures with `tone = 'neutral'`, `empty = 'Nothing here'`, and makes an id with a module counter (`board-column-${++next}`), as Sparkline and Chart do, for `aria-labelledby`. Markup:

```svelte
<section
  bind:this={ref}
  data-slot="board-column"
  aria-labelledby={headingId}
  class={cn('flex w-72 shrink-0 flex-col gap-2 rounded-xl bg-foreground/[0.04] p-2', className)}
  {...rest}
>
  <header class="flex items-center gap-2 px-1 py-1">
    <span data-slot="board-column-dot" class={cn('size-2 shrink-0 rounded-full', TONE_FILL_CLASS[tone])}></span>
    <h3 id={headingId} class="truncate text-sm font-medium">
      {#if typeof title === 'string'}{title}{:else}{@render title()}{/if}
    </h3>
    {#if count !== undefined}
      <span data-slot="board-column-count" class="text-muted-foreground text-sm tabular-nums">{count}</span>
    {/if}
    {#if actions}<div class="ml-auto">{@render actions()}</div>{/if}
  </header>
  {#if children}
    <div data-slot="board-column-cards" class="flex flex-col gap-2">{@render children()}</div>
  {:else}
    <p data-slot="board-column-empty" class="text-muted-foreground px-1 py-6 text-center text-sm">
      {#if typeof empty === 'string'}{empty}{:else}{@render empty()}{/if}
    </p>
  {/if}
</section>
```

`children` absent means empty: a caller with an empty list passes no children (an `{#each}` that renders nothing still passes a snippet, so the fixture and the docs say to wrap the `{#each}` in `{#if items.length}`). If that proves awkward in the example, add an explicit `empty` boolean in a follow-up rather than guessing from the DOM.

`board-card.svelte`: `BoardCardProps = WithElementRef<HTMLAnchorAttributes>` (with `href` deciding the element), rendering `<svelte:element this={href ? 'a' : 'div'}>` like Badge, `data-slot="board-card"`, classes `bg-card text-card-foreground flex flex-col gap-1 rounded-lg border p-3 text-sm shadow-xs`, plus for a link `hover:bg-accent/40` is **not** used (`--accent` is the active nav row only): use `hover:border-foreground/20 focus-visible:ring-ring/50 outline-none focus-visible:ring-[3px] transition-colors`.
